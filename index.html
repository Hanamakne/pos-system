ລະບົບນີ້ໃຊ້ Google Sheet ເປັນຖານຂໍ້ມູນກາງ ເພື່ອໃຫ້ທຸກເຄື່ອງ/ທຸກ browser ທີ່ເປີດດ້ວຍ URL ດຽວກັນເຫັນຂໍ້ມູນຮ່ວມກັນ.

ຖ້າຍັງບໍ່ໄດ້ຕັ້ງຄ່າ ໃຫ້ເຮັດຕາມຂັ້ນຕອນທີ່ Claude ອະທິບາຍໄວ້ (ສ້າງ Google Sheet → ເປີດ Apps Script → ວາງໂຄດ → Deploy ເປັນ Web App) ແລ້ວເອົາ URL ທີ່ໄດ້ມາວາງໃສ່ຊ່ອງລຸ່ມນີ້.

ນຳເຂົ້າສິນຄ້າ

ຮອງຮັບໄຟລ໌ .csv (ແນະນຳ — ອ່ານໄດ້ໄວແລະໜັກແໜ້ນທີ່ສຸດ), .xlsx, .xls — ຖ້າຂໍ້ມູນຢູ່ໃນ Google Sheet ໃຫ້ໄປທີ່ File → Download → Comma Separated Values (.csv) ແລ້ວອັບໂຫລດໄຟລ໌ນັ້ນຢູ່ບ່ອນນີ້.
ຄໍລຳທີ່ຮອງຮັບ (ໃສ່ຫົວຕາຕະລາງແຖວທຳອິດ): ບາໂຄດ, ຊື່ສິນຄ້າ, ໜ່ວຍ, ລາຄາທຶນ, ລາຄາຂາຍ, ຄົງເຫຼືອ (ຫຼືໃຊ້ຄຳວ່າ barcode, name, unit, cost, price, stock ກໍໄດ້) — ຕ້ອງມີຢ່າງໜ້ອຍຄໍລຳ "ຊື່ສິນຄ້າ"
ກົດເພື່ອເລືອກໄຟລ໌ ຫຼື ລາກໄຟລ໌ມາວາງທີ່ນີ້
ໃນ Google Sheet: File → Share → Publish to web → ເລືອກຊີດ → ຮູບແບບ CSV → ກົດ Publish ແລ້ວກັອບປີ້ລິ້ງມາວາງທີ່ນີ້.
ໝາຍເຫດ: ບາງ Google Sheet ອາດຈະບໍ່ອະນຸຍາດໃຫ້ດຶງຂໍ້ມູນຜ່ານລິ້ງໂດຍກົງ ຖ້າດຶງບໍ່ໄດ້ ໃຫ້ໃຊ້ວິທີອັບໂຫລດໄຟລ໌ແທນ.
